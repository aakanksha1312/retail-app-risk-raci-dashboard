# 🛒 Retail App Launch - PMO Dashboard

## 📌 Project Overview
A Project Management dashboard built in Excel for a Retail E-Commerce App launch.

## 📊 What I Built

### Sheet 1: Risk Register
- 8 project risks identified
- Scoring: Probability x Impact = Risk Score
- Auto RAG status: High/Medium/Low using IF formula
- Mitigation vs Contingency plans
- Live OVERDUE tracker using =TODAY() formula
- Conditional formatting

### Sheet 2: RACI Matrix
- 8 tasks x 5 stakeholders
- Golden Rule: Only ONE Accountable (A) per task
- Color-coded with Conditional Formatting
    - A = Yellow (Boss)
    - R = Green (Worker)
    - C = Blue (Consulted)
    - I = Grey (Informed)
- Added LEGEND for clarity

## 🛠 Tools Used
- MS Excel
- Formulas: IF, TODAY, Multiplication
- Conditional Formatting
- Project Management Concepts

## 🎯 Key Learnings
- Difference between Mitigation & Contingency
- Why only ONE 'A' in RACI
- Risk scoring logic
